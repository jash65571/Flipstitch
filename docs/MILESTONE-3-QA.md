## What changed in this milestone

- Original synthesized sound system (`expo-audio`): nine local WAV effects
  generated by `scripts/generate-sounds.mjs`, validated by
  `scripts/validate-audio.mjs`, played through one audio service with
  per-sound throttling and safe teardown.
- One feedback controller: semantic events → sound + haptic, honoring
  Sound Off / Haptics Off, with per-group haptic dedupe. Android uses
  `performAndroidHapticsAsync`; iOS uses the impact/notification/selection
  family.
- Settings screen (gallery → Settings): sound/haptics switches, live reduced
  motion status, playtest view/export (report + raw JSON), clear playtest
  data, reset progress with confirmation, and about/license info.
- Local playtest instrumentation: schema-versioned events with session id,
  sequence, timestamp, and monotonic elapsed time, stored in a bounded
  AsyncStorage store (5000 events, oldest dropped), debounced writes, no
  network code (scan-verified).
- Pure playtest report engine with all milestone metrics and explicit
  small-sample warnings.
- CI: `workflow_dispatch` added, audio + analytics-scan steps added, push
  checks on `main` preserved.
